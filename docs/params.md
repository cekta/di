# Параметры

Возможность задавать конкретные значения для аргументов конструктора.

Они позволяют:

- передавать встроенные типы (`string`, `int`, `array` и т. д.)
- переопределять значения по умолчанию
- передавать конкретные экземпляры объектов

## Имена параметров

Каждый параметр имеет **имя** — ключ в конфигурации.  
Имена могут быть [глобальными и локальными](dependency-naming.md).

> 💡 По умолчанию используйте **локальные** имена. Они делают конфигурацию предсказуемой.

## Пример внедрения параметров

**src/Example.php**

```php
<?php
declare(strict_types=1);

namespace App;

class Example
{
    public function __construct(
        public string $firstName,
        public string $lastName,
    ) {}
}
```

**src/Manifest.php**

```php
<?php
declare(strict_types=1);

namespace App;

class Manifest extends \Cekta\DI\Manifest
{
    public function __construct()
    {
        parent::__construct(
            filename: __DIR__ . '/../Container.php',
            fqcn: 'App\Container',
            params: [
                \App\Example::class . '$firstName' => 'Ivan',
                \App\Example::class . '$lastName' => 'Ivanov',
            ],
            definition: [
                'entries' => [\App\Example::class],
            ]
        );
    }
}
```

## Обязательные параметры

Это параметры, которые использовались на этапе [генерации контейнера](generate.md) для разрешения зависимостей.

Обязательные параметры необходимо передавать в runtime. Если после генерации контейнера убрать обязательные параметры
из `Manifest`, то это приведёт к ошибке создания контейнера, так как целевые зависимости могут оказаться не разрешимы.

Для исключения таких сложно воспроизводимых ошибок `Container` при создании проверяет, переданы ли все обязательные
параметры.

## Значения по умолчанию

Если в аргументах конструктора есть значения по умолчанию, то их можно не задавать — будет использовано значение по умолчанию.

Заданные параметры переопределяют значения по умолчанию аргументов конструктора.

## Отложенные значения (Lazy)

Параметры вычисляются каждый раз в runtime (значения из runtime переопределяют значения параметров с этапа генерации).

Если нужно отложить вычисление до runtime — см. [Отложенные значения](lazy.md).
