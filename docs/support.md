# Поддержка

Если у вас остались вопросы по текущей документации или есть проблема с настройкой в вашем проекте, вы можете:

1. [Создать issue](https://github.com/cekta/di/issues) на русском или английском языке.
2. Написать в [русскоязычный чат](https://t.me/dev_ru).

Также здесь можно оставить предложения по улучшению библиотеки.

> 💡 Проект открыт для pull request'ов с улучшениями!
