# Введение

Реализация [PSR-11](https://www.php-fig.org/psr/psr-11/) с компиляцией графа зависимостей на этапе сборки.

**Требования:** PHP 8.2+

## Преимущества

- **Скорость** — нет накладных расходов в рантайме: контейнер готов сразу
- **Оптимизация** — работает напрямую с opcache, не требует кэширования
- **Безопасность** — ошибки конфигурации обнаруживаются на этапе сборки
- **Гибкость** — генерируйте код при деплое, в CI/CD или при первом запуске, как вам удобно

## Важно

Сборка обязательна — необходимо организовать этап генерации кода. Это нетипично для PHP, но именно это обеспечивает высокую производительность.
